# Artificer for Obsidian · Changelog

User-visible changes to the Artificer Obsidian theme, distributed via BRAT and
GitHub releases. The theme tracks the Artificer system version.

## 0.19.0

First public release of the Artificer Obsidian theme.

- Monospace-first, dark-by-default theme with a paper-cream light mode.
- ~40 Style Settings controls; eight accent colors with separate dark/light defaults.
- Self-contained `theme.css` — JetBrains Mono + iA Writer Quattro inlined.
